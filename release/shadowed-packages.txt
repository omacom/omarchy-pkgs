# Package names this repository publishes for x86_64 that Arch also ships,
# one per line with the reason Omarchy carries its own build.
#
# Omarchy's pacman.conf lists [omarchy] above [core], [extra] and [multilib],
# and pacman takes a name from the first repository that has it. So every
# name here replaces Arch's build on every machine, and keeps replacing it
# after Arch's is newer. bin/check-shadowed fails on a name Arch ships that
# this file does not list, and on a listed name that falls behind Arch.
#
# Shadow Arch only for Omarchy's own stack. An application that Arch ships
# stays on Arch's build on x86_64, however old, unless someone here owns its
# updates for good.
ghostty Built with a pinned Zig toolchain on both architectures
ghostty-nautilus Split package of ghostty
ghostty-shell-integration Split package of ghostty
ghostty-terminfo Split package of ghostty
hyprland Carries Omarchy's patches and moves with omarchy-hyprland-titlebars
hyprpm Split package of hyprland
lib32-nvidia-utils In step with nvidia-utils
lib32-opencl-nvidia Split package of lib32-nvidia-utils
limine Carries the quiet_wallpaper patch for Omarchy's boot screen, and follows each upstream release
nvidia-open-dkms In step with the linux-omarchy-nvidia-open modules both linux-omarchy recipes build
nvidia-utils In step with nvidia-open-dkms and the linux-omarchy-nvidia-open modules
opencl-nvidia Split package of nvidia-utils
quickshell The Omarchy shell's runtime, built past its last release and rebuilt on Qt updates
yt-dlp YouTube breaks stale builds; the upstream zipapp, tracked hourly on the fast ring
