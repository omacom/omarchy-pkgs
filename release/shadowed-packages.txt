# Package names this repository publishes for x86_64 or aarch64 that Arch or
# Arch Linux ARM also ships, one per line with the reason Omarchy carries its
# own build.
#
# Omarchy's pacman.conf lists [omarchy] above the official repositories
# ([core], [extra], [multilib] on x86_64; [core], [extra], [alarm] on installed
# aarch64 systems plus [aur] in the aarch64 builder and online installer ISO),
# and pacman takes a name from the first repository that has it. So
# every name here replaces the official build on every matching machine, and
# keeps replacing it after upstream is newer. bin/check-shadowed fails on a
# name upstream ships that this file does not list, and on a listed name that
# falls behind upstream.
#
# Shadow upstream only for Omarchy's own stack. An application that Arch or
# Arch Linux ARM ships stays on the official build, however old, unless someone
# here owns its updates for good.
