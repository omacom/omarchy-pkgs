This package supplies the nine Dell XPS 13 DX13260 Panther Lake `10280e54` firmware aliases, under `/usr/lib/firmware/updates/cirrus`. The kernel and mkinitcpio search this directory before the stock firmware directory. A package-owned mkinitcpio drop-in explicitly includes all nine links and their targets in the boot image, because module firmware globs alone do not include every speaker ID. Each link targets the exact existing Wildcat Lake tuning or Rev4.5.9 firmware target used by Arch’s native aliases. Stock `linux-firmware-cirrus` continues to own and update every firmware binary; this package neither provides nor conflicts with it.

Omarchy integration should install this package on every matching XPS 13 DX13260 Panther Lake machine, including machines currently using native firmware. Keeping its package identity installed lets a channel downgrade restore the overlay through pacman alone, even after migrations have completed. The initial links exactly match the current native aliases; a later native-firmware channel transition removes the overlay payload. Listing it in `omarchy-other.packages` makes it available offline without installing it on other hardware. It can coexist with both the old same-name Omarchy shim and native Arch firmware; a stable refresh may remove the old shim’s aliases without removing these separately owned links.

When a channel’s core snapshot supplies native aliases, publish a higher-version empty transitional package depending on `linux-firmware-cirrus>=20260910-2`, with no firmware links or mkinitcpio drop-in. The existing Omarchy firmware path hook rebuilds the UKIs when the links are removed; no new hook is needed. That transaction removes the overlay while upgrading stock firmware, so the native aliases take over. Publish the transition only after the channel supplies the required stock version, and retain it for late updaters. Keep the earlier overlay package in older channels: a downgrade from the native transition back to an older snapshot must downgrade both packages together and restore the links. Do not publish the higher native dependency to an older channel. Removing this recipe or its repository entry alone leaves installed overlays in place and could mask future native PTL tuning.

This package does not replace the separate Panther Lake display workaround.
