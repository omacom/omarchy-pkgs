# Hyprland

Automatic upstream version bumps are held (`sync: false`) because `omarchy-hyprland-titlebars` requires the exact Hyprland it was built against, and a new Hyprland release can break the plugin's build. 0.57.0 did, so the plugin's rebuild failed and every `pacman -Syu` that offered Arch's 0.57.0 stopped on its `hyprland=0.56.2` dependency. Bump Hyprland by hand, in the same change as a plugin release that builds against it. Hyprland is on the normal ring, so a merge publishes it to edge only, and rc and stable get it by promotion together with the plugin. Aquamarine changes in the official/ALARM repositories are checked by the separate six-hour `sync-rebuilds` job through `rebuild_on`, which proposes a package release bump for rebuilding.

## Output, VRR, and NVIDIA fixes

`wl-output-global-grace.patch` keeps a removed `wl_output` global for five seconds before destroying it, as wlroots does. Without it, an output that comes and goes within a roundtrip, such as a dock's monitor flapping while its tunnel comes up, disconnects every client that has not bound it yet with "global wl_output (N) is unavailable". `monitor-rule-vrr.patch` makes a config reload apply a monitor rule's `vrr`; without it, changing only `vrr` is ignored until the next session. `nvidia-egl-teardown.patch` releases the EGL context before Hyprland terminates the display, which NVIDIA's EGL otherwise crashes on at exit. Two earlier carries, the removed-output session-lock fix and the dmabuf format-table fix, shipped upstream in 0.57.1 and were dropped here. `alpha-only-primary-plane.patch` lets Hyprland start on a display whose primary plane offers only formats with alpha. The 15-inch M5 MacBook Air (J815) is one: its display firmware blends the X byte of an XRGB buffer as alpha, so appledrm offers ARGB and ABGR there but no XRGB. Hyprland tests every mode with XRGB8888, so each test failed and Hyprland aborted, and the SDDM greeter with it. On such a plane the patch tests modes with ARGB8888, tries the alpha formats after the XRGB ones, and reads the monitor back as its opaque twin for screen sharing. A plane that offers any format without alpha, as on PCs and M1 to M3 Macs, picks formats as before. It is an Omarchy carry only: Hyprland's AI policy rules out sending this patch upstream. Rebase each patch with `--fuzz=0` on a version bump, and drop each once the selected release carries the fix.

## x86_64

This recipe also builds for x86_64, so PCs take this build instead of Arch's `extra/hyprland`: `[omarchy]` comes before `[extra]` in Omarchy's `pacman.conf`. That gives PCs the patches above and keeps them on the Hyprland the titlebars plugin was built against when Arch moves first. Move both architectures and the plugin to a newer Hyprland in one change, with a `pkgrel` above Arch's for the same version so a machine already on Arch's build moves to this one.
