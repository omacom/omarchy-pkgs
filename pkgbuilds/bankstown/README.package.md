# bankstown

James Calligeros' bass enhancer, an LV2 plugin. `aurora-audio`'s speaker DSP chains use it to add perceived bass the small Apple Silicon speakers can't reproduce.

Built from the chadmed/bankstown 1.1.0 tag. The recipe follows asahi-alarm's: same name, same `pkgver`, a higher `pkgrel`, so a Mac that has asahi-alarm's build takes this one at its next update. The plugin installs to `/usr/lib/lv2/bankstown.lv2/`, as before.
