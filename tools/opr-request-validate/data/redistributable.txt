# Licenses under which OPR may build, sign and host binaries itself
# (`surface = "binary"`). Rule 8 of docs/request-schema.md.
#
# Inclusion means the license grants us the right to redistribute compiled
# artifacts. It says nothing about whether the package is desirable, and it is
# not legal advice — it is the machine-checkable half of a question that ends
# with a human.
#
# This list is deliberately conservative. A license that is absent is not
# refused, it is unreviewed: the request is rejected with that reason and a
# maintainer can add the identifier in a reviewed PR. Absence must never be
# silently downgraded to the recipe surface, because the requester should know
# which surface they are getting.
#

# does not define its allowlist. Treat the contents as a proposal for review,
